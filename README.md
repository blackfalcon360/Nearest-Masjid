# Nearest Masjid

آپ کی موجودہ جگہ سے قریب ترین مسجد کا فاصلہ اور سمت دکھاتی ہے۔

## ایپ کیا کرتی ہے
- بڑا کارڈ: قریب ترین مسجد کا نام، فاصلہ (m/km)، سمت اور گھومتا ہوا تیر۔
- نیچے اگلی 25 قریبی مساجد؛ ٹیپ کریں تو نقشے کی ایپ میں کھلتی ہے۔
- مساجد کا ڈیٹا OpenStreetMap سے آتا ہے (نئے علاقے میں خود، یا "ریفریش" بٹن) اور فون میں محفوظ رہتا ہے، پھر اسی علاقے میں بغیر انٹرنیٹ بھی چلتا ہے۔
- زبان: اردو / English / العربية؛ لائٹ اور ڈارک موڈ؛ باہر نکلنے سے پہلے تصدیق۔

## بِلڈ
1. فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions میں "Build APK" چلے گا۔
3. Artifacts سے `NearestMasjid-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- صرف portrait؛ AndroidX یا بیرونی لائبریری نہیں۔
- کسی علاقے میں پہلی بار انٹرنیٹ لازمی ہے؛ بغیر انٹرنیٹ صرف پہلے محفوظ کیا ہوا علاقہ چلے گا۔
- فاصلہ سیدھی لکیر میں ہے، راستے کا نہیں۔
- OpenStreetMap رضاکاروں کا بنایا ہوا ہے؛ کچھ مساجد درج نہ ہوں یا بے نام ہوں تو ممکن ہے۔
- ڈاؤن لوڈ کے وقت آپ کا مقام OpenStreetMap کے سرور کو جاتا ہے؛ سیٹنگز میں خودکار ڈاؤن لوڈ بند ہو سکتا ہے۔
